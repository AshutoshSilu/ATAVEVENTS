# AtAv Events

A premium responsive Angular web application for cultural events, corporate experiences, DJ nights, live shows, celebrations, and event registration.

## Tech Stack

- Angular 21 standalone components with lazy-loaded route components
- Angular Router and Reactive Forms
- SCSS global styling
- Tailwind CSS utility-first UI design
- Mock JSON-style data through an injectable Angular service

## Run Locally

```bash
npm install
npm start
```

## Build

```bash
npm run build
```
